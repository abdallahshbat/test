# منصة حفّاظ - Huffaz Platform Database

## الجداول

| الجدول | الوصف |
|--------|-------|
| `users` | جميع المستخدمين (مشرف، معلم، طالب) |
| `programs` | برامج الحفظ |
| `teachers` | بيانات المعلمين |
| `students` | بيانات الطلاب مع ربطهم بالمعلم والبرنامج |
| `student_plans` | الخطة اليومية لكل طالب |
| `recitation_sessions` | جلسات التسميع |
| `attendance` | سجل الحضور والغياب |
| `periodic_exams` | الاختبارات الدورية |
| `daily_reviews` | المراجعات اليومية |

## صلاحيات RLS

| الدور | الصلاحية |
|-------|----------|
| مشرف (admin) | يرى ويعدل كل البيانات |
| معلم (teacher) | يرى ويعدل بيانات طلابه فقط |
| طالب (student) | يرى بياناته الخاصة فقط |

## التطبيق

supabase db push
